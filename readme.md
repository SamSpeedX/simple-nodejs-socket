# ⚡ Cart Socket Server (Node.js + Socket.IO)
This project is a real-time socket server built with **Node.js, Socket.IO, and Axios**, integrated with a **Laravel backend API** for authentication and database operations.

## It powers real-time features like:
- Real-time sync between users

## Before running this project, make sure you have installed:
- Node.js (v20+ recommended)
- npm or yarn
- backend API running
- PM2 (optional for production)



# 🚀 Installation

Clone the project:
```bash
git clone https://your-repo-url.git
cd socket-server
```

Install dependencies:
```bash
npm install
```

## 📁 Project Structure
```
server.js        → Socket.IO server
index.js         → Client test file
deploy.sh        → Bash script for deploy use pm2 on VPS
```
